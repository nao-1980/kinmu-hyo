# 勤務表作成ツール

医療法人向けの月次シフト作成ツールです。ブラウザだけで動作し、サーバーを必要としません。

**確認用バージョン v0.9（2026-07-29）**

---

## ⚠️ 取り扱いについて

このリポジトリは GitHub Pages で公開されます。

- **職員の氏名・社員番号を含むファイルをコミットしないでください**
- 保存した JSON、書き出した CSV、ハーモス勤怠の出力は `.gitignore` で除外しています
- 公開されるのはツール本体のみで、データは各自の端末に保存されます

---

## できること

| 機能 | 内容 |
|---|---|
| 勤務予定の入力 | プルダウンで11区分から選択。年月に応じて日数と曜日が自動で切り替わります |
| 部署の切り替え | 部署ごとに別々の勤務表を保持します |
| 勤務実績日数 | 区分別の日数を自動集計。部署合計と未入力数も表示します |
| 出勤人数 | 日ごとの出勤人数を自動計算。基準を下回る日は赤で表示します |
| 行事・特記 | 日付をクリックして記入。一覧は下段に日付順で表示します |
| 職員の削除 | 削除しても記録は「削除済みの職員」に残ります |
| 締切ロック | 前月は管理者のみ編集可（変更履歴に記録）。それ以前は編集不可 |
| 保存・読み込み | JSON ファイル。全部署ぶんを1ファイルにまとめます |
| CSV 書き出し | 1行＝1人1日。ハーモス勤怠との照合用 |
| 印刷 | A3 横。予定表・集計・履歴・行事を続けて出力します |

---

## 使い方

1. 年月と部署を選ぶ
2. 氏名と社員番号を入力する
3. 各日のマスで勤務区分を選ぶ
4. 「保存する」で JSON をダウンロード（**ブラウザを閉じると入力内容は消えます**）
5. 次回は「読み込む」で JSON を選択

---

## 設定の変更

`index.html` 冒頭の定数を編集してください。

```javascript
const VERSION = 'v0.9';                    // 確認用バージョン
const DEPARTMENTS = ['管理部', ...];        // 部署の一覧
const CATEGORIES  = [...];                 // 勤務区分（記号・名称・色分け・出勤係数）
const SUM_ORDER   = [...];                 // 集計欄の並び順
const MIN_STAFF_PER_DAY = 2;               // 必要出勤人数（下回ると赤）
```

区分を増減する場合は `CATEGORIES` と `SUM_ORDER` の両方を更新してください。

# 導入手順（Google スプレッドシート版）

所要 15〜20分。プログラムの知識は不要です。

---

## 1. スプレッドシートを作る

クライアントの Google ドライブ（**共有ドライブを推奨**）に、新しいスプレッドシートを作成します。

- 名前の例：`勤務表データ`
- **クライアント側のアカウントで作成してください。** 制作者個人のドライブに置くと、契約終了時にアクセスできなくなります。

---

## 2. スクリプトを貼り付ける

1. スプレッドシートのメニュー → **拡張機能 → Apps Script**
2. 既定の `コード.gs` の中身をすべて消し、**`Code.gs` の内容を貼り付け**
3. 左の「ファイル」の **＋ → HTML** をクリック
4. ファイル名を **`index`** にする（`.html` は不要）
5. 中身をすべて消し、**`index.html` の内容を貼り付け**
6. 保存（⌘/Ctrl + S）

> ファイル名は必ず `index` にしてください。`Code.gs` から `index` を読み込んでいます。

---

## 3. 初期設定を実行する

1. エディタ上部の関数選択で **`setup`** を選ぶ
2. **実行** をクリック
3. 初回は承認画面が出ます
   - 「権限を確認」→ アカウントを選択
   - 「詳細」→「（プロジェクト名）に移動」→「許可」
4. 「セットアップが完了しました」と出れば成功

スプレッドシートに以下のシートができます。

| シート | 内容 |
|---|---|
| 設定 | 管理者・部署・必要出勤人数 |
| 勤務予定 | 1行＝1人1日。人が読む用・分析用 |
| アクセスログ | 誰がいつ開いたか |
| _data | 保存の本体（非表示） |

---

## 4. 設定シートを編集する

| 項目 | 値の例 |
|---|---|
| 管理者 | `shicho@example.jp, jimu@example.jp` |
| 部署 | `管理部, 事務, 診療アシスタント, 看護師, ドライバー, 戸塚院, 港南院` |
| 必要出勤人数 | `2` |

- **管理者に載っていない人は「職員」**になります
- 師長が交代したら、ここを書き換えるだけです（プログラムの修正は不要）

---

## 5. 公開する

1. エディタ右上の **デプロイ → 新しいデプロイ**
2. 歯車 → **ウェブアプリ** を選択
3. 設定
   - 説明：`v3.0`
   - **次のユーザーとして実行：自分**
   - **アクセスできるユーザー：（組織名）内の全員**
4. **デプロイ** → 表示された **ウェブアプリの URL** を控える

> 「アクセスできるユーザー」を「全員」にすると、社外の人も開けてしまいます。
> **必ず組織内に限定してください。**

---

## 6. 動作を確認する

URL を開いて確認します。

| 確認箇所 | 期待される表示 |
|---|---|
| 保存先 | ▦ 勤務表データ / Google スプレッドシート |
| 権限のラベル | `権限（ご自身のメールアドレス）` |
| 権限の選択 | **変更できない**（グレー表示） |
| ヘッダー右 | ● 読み込みました |
| 画面下部 | v3.0 |

氏名を1つ入力してみて、**「保存中…」→「保存しました HH:MM」**と変われば成功です。
スプレッドシートの `_data` シートに行が増えているはずです。

---

## 更新のしかた

`index.html` を修正したら、

1. Apps Script の `index` を差し替えて保存
2. **デプロイ → デプロイを管理 → 鉛筆マーク → バージョン「新バージョン」→ デプロイ**

**URL は変わりません。** 新バージョンを選ばないと反映されないので注意してください。

---

## 仕様と制限

| 項目 | 内容 |
|---|---|
| 権限判定 | Google アカウントで自動。**本人は変更できません** |
| 保存 | 変更の 1.5 秒後に自動。同時保存は待ち合わせます |
| 保存単位 | 年月 × 部署 |
| 1件あたり上限 | 職員 40〜50 名程度 |
| 同時編集 | 後から保存した内容が残ります（**同じ部署を同時に編集しないでください**） |

---

## 職員に配る前に

現時点では、**職員も全員分の勤務表が見える**状態です。
自分の行だけを表示する画面は未実装です。

まずは **管理者（師長・事務担当）だけで1か月運用**し、問題がないことを確認してから配布してください。

---

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「接続できませんでした」 | デプロイのアクセス範囲を確認 |
| 権限が「職員」のまま | 設定シートの管理者欄にメールアドレスがあるか確認 |
| 保存できない | 同時に保存が集中している可能性。少し待って再編集 |
| 画面が古い | デプロイ時に「新バージョン」を選んだか確認 |

---

## バックアップ

`_data` シートが保存の本体です。
月に一度、**ファイル → コピーを作成** でバックアップを取ってください。

確定した勤務表は、ツールの「印刷」から PDF で保存してください。
出勤簿は法定の保存対象です。
